# פורמט ספר הרפתקה – אפליקציית החבורה

המסמך מתאר את הקובץ שהאפליקציה מקבלת בהגדרות ← ספרייה ← "העלאת הרפתקה". זה הבסיס לכל מי שמכין הרפתקה: ידנית, בכלי עזר, או בעזרת Claude עם הסקיל הזה.

## שתי דרכים להעלות

1. **קובץ אחד ארוז** (הדרך המומלצת להעברה בין מנחים):
   ```json
   { "format": "sw-adventure", "version": 1,
     "books": [ { "book": { …ספר… }, "images": { "books/x-map.jpg": "data:image/jpeg;base64,…" } } ] }
   ```
   אפשר כמה ספרים בקובץ אחד. המפתחות ב־`images` הם בדיוק הנתיבים שמופיעים בתוך הספר.
2. **קובץ ספר ותמונות בנפרד**: בוחרים יחד את קובץ ה־json של הספר ואת קובצי התמונות. האפליקציה מתאימה כל תמונה לפי **שם הקובץ בלבד** (בלי התיקייה, בלי הבדל בין אותיות גדולות לקטנות).

לפני השמירה מוצגת בדיקה: שגיאות עוצרות את השמירה, ואזהרות רק מסבירות מה יחסר. תמונה שלא נמצאה מוסרת מהספר (למשל ספר בלי מפה). תמונה מעל כ־900KB מוקטנת אוטומטית.

**עדכון ספר:** העלאה עם אותו `id` מחליפה את הספר בספרייה. ההתקדמות במשחקים שמורה לפי מזהי החדרים, ולכן **לא משנים מזהה של חדר קיים**.

## הספר (book)

| שדה | חובה | מה זה |
|---|---|---|
| `id` | כן | מזהה קבוע: אותיות אנגליות קטנות, ספרות ומקפים, 2–41 תווים. למשל `serpent-kings`. |
| `title` | כן | שם ההרפתקה. |
| `rooms` | כן | רשימת החדרים (לפחות אחד). |
| `source` | | מקור ועמודים, למשל `"קבר מלכי הנחשים, עמ' 2–29"`. |
| `levels` | | דרגות ומספר דמויות, טקסט חופשי. |
| `summary` | | תקציר למנחה. |
| `readNote` | | הערה על קטעי ההקראה (למשל שהם תמצית). אם יש, קטעי ההקראה מסומנים "(תמצית)". |
| `intro` | | פתיחה: `{read, dm:[…], page}`. |
| `goals` | | מטרות עם נק״ן: `[{id, name, xp, perChar, page}]`. `perChar: true` = הנק״ן לכל דמות. |
| `flags` | | אירועים שהמנחה מסמנת שקרו: `[{id, name, page}]`. |
| `after` | | מה קורה אחרי ההרפתקה. |
| `adjust` | | הוראות התאמה כלליות: `{page, maxLvl, note}`. |
| `map` | | מפה, ראו למטה. |

## חדר (room)

| שדה | מה זה |
|---|---|
| `id` | **חובה, ייחודי.** מחרוזת, בדרך כלל מספר החדר בחוברת (`"12"`). |
| `name` | שם החדר. |
| `page` | עמוד, למשל `"עמ' 11"`. |
| `read` | טקסט להקראה לשחקנים. |
| `dm` | רשימת הערות למנחה. |
| `secret` | מה מגלים בחיפוש (דלתות סודיות וכו'). |
| `exits` | יציאות, טקסט. |
| `monsters` | מפלצות, ראו למטה. |
| `adjust` | התאמת מפלצות לחבורה, ראו למטה. |
| `traps` | מלכודות, ראו למטה. |
| `treasure` | אוצר, ראו למטה. |
| `events` | אירועים בחדר: `[{text, flag, fight:{from, label}}]`. `flag` מסמן אירוע מ־`flags`; `fight.from` = מזהה חדר שהמפלצות שלו מצטרפות לקרב כאן. |
| `flagNotes` | הערה שמופיעה כשאירוע מסומן: `{ "flag-id": "טקסט" }`. |
| `tables` | טבלאות גלגול: `[{name, die:"1ק8", page, rows:[[מ, עד, "טקסט"]]}]`. |

### מפלצת
```json
{ "name": "שלד", "count": 3, "hd": "2", "ac": 11, "atk": "טופרים (1ק6)", "save": 16, "move": 12, "xp": 30, "special": "…" }
```
- `hd`: קוביות פגיעה כמו בחוברת: `"2"`, `"6+4"`, `"1ק6"` (נק״פ ישירות), `"½"`. האפליקציה מגלגלת נק״פ ומחשבת תוסף התקפה.
- `hp`: נק״פ קבועות, אם החוברת נותנת.
- `atkb`: תוסף התקפה, רק אם החוברת קובעת אחרת מהרגיל.
- `count`, `ac`, `save`, `xp`: מספרים. `name` חובה, ומשמש גם לספירת המובסות.

### התאמה (adjust)
`[{mon, op, v, when, to, note}]`, לפי נספח ההתאמה בחוברת:
- `op`: `cap` (לא יותר מ־v), `add` (להוסיף v), `set` (בדיוק v), `swap` (להחליף ב־`to`), `stat` (לשנות נתונים לפי `to`), `noevent` (להסתיר אירוע מספר v).
- `v`: מספר, `"n"` = מספר הדמויות, `"avg+1"` = הדרגה הממוצעת ועוד 1.
- `when`: `{lvl, lvlMax, nMin, nMax}`: לפי הדרגה שרוב החבורה הגיעה אליה ולפי מספר הדמויות.

### מלכודת
```json
{ "name": "בור", "text": "…", "dmg": "1ק6", "xp": 100, "hits": { "first": 1, "all": false, "half": true, "note": "…" } }
```
`dmg` בגלגול קוביות (`"2ק4+6"`). `hits` קובע על מי זה נופל לפי סדר ההליכה: `first` = כמה ראשונים, `all` = כולם, `half` = כפתור חצי נזק בהצלה. `xp` = נק״ן לקופה כשמסמנים שהחבורה התמודדה.

### אוצר
- כסף: `{ "name": "16 מטבעות זהב", "text": "…", "gp": 16 }` (נותן כפתור חלוקה לחבורה; ערך במ״ז, כסף = 0.1).
- פריט מהחנות: `{ "name": "4 לפידים", "ref": "torch", "qty": 4 }` (`ref` = מזהה הפריט באפליקציה).
- פריט אחר: `{ "name": "פגיון +1", "text": "…", "item": true }`, או עם `qty`.

## מפה (map)

```json
"map": {
  "file": "books/x-map.jpg", "page": "עמ' 6", "note": "…",
  "pins": { "1": [9.3, 15.6], "2": [14.7, 10.3] },
  "players": {
    "file": "books/x-map-players.jpg", "note": "…",
    "regions": { "1": [ [[7.9,13.2],[29.7,13.2],[29.7,17.4],[7.9,17.4]] ] },
    "patches": [ { "room": "8", "box": [x0, y0, x1, y1], "file": "books/x-room8.png" } ]
  }
}
```
- כל הקואורדינטות **באחוזים** מרוחב וגובה התמונה (0–100), מהפינה השמאלית העליונה.
- `pins`: סיכה לכל חדר במפת המנחה (מזהה חדר ← [x, y]).
- `players.file`: מפה לשחקנים, בלי מספרים ובלי סימוני מנחה (דלתות סודיות, מלכודות).
- `players.regions`: לכל חדר רשימת מצולעים. השחקנים רואים רק את האזורים של חדרים שסומנו "ביקרו" או "נוקה".
- `players.patches`: תמונה שמודבקת על המפה כשחדר מתגלה (למשל חדר סודי מאחורי קיר רגיל).
- רק `players` (ותמונותיו) נגישים לשחקנים. כל השאר, כולל מפת המנחה, נפתח רק למנחים.
